# Getting Started

## Prerequisites

| Requirement | Version | Notes |
|-------------|---------|-------|
| Node.js | >=18.0.0 | JavaScript runtime environment |
| npm or yarn | Latest | Package manager |
| Anthropic API Key | Valid key | For authenticating with Claude API |

## Installation

### Install Using npm

```bash
npm install -g @anthropic-ai/claude-code
```

### Verify Installation

```bash
claude --version
```

**Expected Output:**

```
2.1.88
```

## Configuration

On first use, you need to authenticate with your Anthropic account. Claude Code supports two authentication methods: OAuth login and API Key configuration.

### OAuth Login

```bash
claude login
```

This will open a browser for the OAuth authorization flow.

### API Key Configuration

If you already have an API key, configure it via environment variable:

```bash
export ANTHROPIC_API_KEY=<your-api-key>
```

Or set it in the configuration file `~/.claude/settings.json`:

```json
{
  "api-key": "<your-api-key>"
}
```

### Main Configuration Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `api-key` | string | none | Anthropic API key |
| `model` | string | claude-opus-4-5 | Model to use |
| `max-tokens` | number | 8192 | Max tokens per response |
| `temperature` | number | 1 | Generation temperature parameter |
| `base-url` | string | Anthropic API | API base URL |

## First Example (Step by Step)

### Step 1: Start an Interactive Session

```bash
claude
```

After starting, you will see the welcome message and prompt:

```
╭──────────────────────────────────────────────────╮
│  Welcome to Claude Code                          │
│                                                  │
│  I'm powered by Claude, Anthropic's AI assistant│
│                                                  │
│  Type /help for available commands              │
╰──────────────────────────────────────────────────╯

You: _
```

### Step 2: Chat with Claude

Ask Claude to explain some code:

```
You: Explain the structure of this project
```

Claude will analyze the codebase and provide a detailed explanation of the project structure.

### Step 3: Use Slash Commands

Claude Code supports various slash commands:

```
You: /help
```

**Expected Output:**

```
Available commands:
  /help     - Show help information
  /config   - Manage configuration settings
  /login    - Log in to Anthropic account
  /logout   - Log out
  /tasks    - Show current task list
  /commit   - Commit changes
  /review   - Code review
  /diff     - Show changes
  /compact  - Compact context
  /model    - Switch AI model
  ...
```

## Common Commands

| Command | Description | Example |
|---------|-------------|---------|
| `/help [command]` | Show help | `/help commit` |
| `/config` | Open config menu | `/config` |
| `/model [name]` | Switch model | `/model opus` |
| `/tasks` | View task list | `/tasks` |
| `/commit [message]` | Commit changes | `/commit "fix: bug"` |
| `/review [path]` | Code review | `/review src/` |
| `/diff` | View changes | `/diff` |
| `/compact` | Compact context | `/compact` |
| `/clear` | Clear session | `/clear` |
