# claude-code-sourcemap-wiki

> 本项目仅供学习参考

**[English](./README_en.md)** | **中文**

---

基于 [claude-code-sourcemap](https://github.com/ChinaSiro/claude-code-sourcemap) 自动生成的 Wiki 文档

借助 Trae、[nium-wiki](https://github.com/niuma996/nium-wiki) (skill) 和 MiniMax-M2.7-highspeed 完成构建

## 本地预览

```bash
npx nium-wiki serve
```

启动后访问 [localhost:4000](http://localhost:4000) 查看

## 目录结构

- `.nium-wiki/` — nium-wiki 自动生成的 Wiki 文档
- `insights/` — 代码走读的启发点杂记
